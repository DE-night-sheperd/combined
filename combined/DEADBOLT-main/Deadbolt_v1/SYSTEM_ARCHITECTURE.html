0. System Summary

Deadbolt is a comprehensive file access control security system featuring:

  • Rule-based file/folder protection
  • Token-based authentication
  • Real-time file system monitoring
  • 🧠 AI Neural Web for behavioral analysis
  • Kernel-mode & user-mode enforcement

1. System Features

📁 Rule Management

Add/remove rules for files/folders. Types: Block All, Read, Write, Delete, Rename

🔐 Token Auth

Level 1 Token Key with complexity requirements. Encrypted storage via DPAPI.

👁️ Real-time Monitor

Watchdog-based monitoring for file modifications, deletions, creations, moves.

🧠 AI Neural Web

Behavioral analysis, anomaly detection, suspicious pattern recognition, risk scoring.

⚙️ Kernel Driver

Windows file system minifilter for kernel-level IRP filtering.

💾 Persistent Storage

Rules, token, and AI model stored in ~/.deadbolt/ directory.
